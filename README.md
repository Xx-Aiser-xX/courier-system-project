# Courier Service System (Microservices)

> **Обратите внимание:** Этот проект разработан в образовательных целях.
> Главная цель - **изучение и демонстрация современных технологий** (Microservices, Event-Driven Architecture, gRPC, GraphQL, Keycloak), а не создание коммерчески готовой бизнес-логики.

Микросервисная система для управления доставками с распределением заказов в реальном времени.

**Методология разработки:**
Разработка проекта велась по принципу **"Сверху-вниз" (Top-Down)**: от проектирования общей архитектуры и API-контрактов (REST, gRPC, Events) к реализации конкретной логики микросервисов.

---

## Технологический стек

Проект построен на базе **Java 21** и **Spring Boot 3**.

### Архитектура и Коммуникация
*   REST API & HATEOAS: Основное взаимодействие с клиентами. Реализована гипермедиа (сборка ссылок на ресурсы) для навигации по API.
*   GraphQL (Netflix DGS): Альтернативный API для гибкого получения данных.
*   gRPC: Высокопроизводительное синхронное взаимодействие между сервисами.
*   RabbitMQ: Асинхронный обмен сообщениями (Event-Driven).
    *   Patterns: Topic Exchange, Fanout, Dead Letter Queue (DLQ).
*   WebSocket: Уведомления пользователям и курьерам в реальном времени.

### Данные и Безопасность
*   PostgreSQL: Основное хранилище данных.
*   Spring Data JPA: Работа с БД.
*   Keycloak: Identity Provider (OAuth2 / OIDC). Управление пользователями, ролями и токенами.
*   MapStruct: Эффективный маппинг DTO <-> Entity.

### Observability (Наблюдаемость)
*   Zipkin: Распределенная трассировка (Tracing).
*   Prometheus & Grafana: Сбор и визуализация метрик.

### Инфраструктура
*   Docker & Docker Compose: Оркестрация контейнеров.
*   Maven: Сборка проекта.

## Структура сервисов

| Сервис | Порт | Описание |
| :--- | :--- | :--- |
| **`couriers`** | `:8089` | **Core Service**. API для клиентов/курьеров, управление заказами, диспетчеризация. |
| **`pricing-service`** | `:9090` (gRPC) | Расчет стоимости доставки. Реализован как **"чёрный ящик"**, инкапсулирующий логику тарификации. |
| **`notification-service`** | `:8083` | WebSocket сервер для пуш-уведомлений. |
| **`audit-service`** | `:8082` | Логирование всех событий системы (слушает RabbitMQ). |
| **`statistics-service`** | `:8081` | Сбор бизнес-статистики (выручка, кол-во заказов). |

## Документация API

Проект поддерживает автоматическую генерацию документации для REST API, а также имеет строгий контракт для GraphQL.

*   Swagger UI (REST): Интерактивный интерфейс для просмотра и тестирования эндпоинтов. Реализован с помощью `springdoc-openapi`.
    *   URL: `http://localhost:8089/swagger-ui.html`
*   OpenAPI Specification: Сырая спецификация API в формате JSON (v3).
    *   URL: `http://localhost:8089/v3/api-docs`
*   GraphQL Schema: Схема API определена в файле `schema.graphqls`. GraphiQL интерфейс доступен для отладки запросов.
    *   URL: `http://localhost:8089/graphiql` (или `/graphql`)

## Запуск проекта

Для запуска требуется **Docker** и **Java 21**.

### 1. Сборка и Запуск
Используйте `Makefile` для автоматизации (или команды maven/docker вручную).
Сборка библиотек и сервисов + Запуск контейнеров.
```bash
make
```
Если Makefile недоступен:
1. mvn clean install -f events-contract/pom.xml (и другие контракты)
2. mvn clean package -DskipTests (для всех сервисов)
3. docker compose up -d --build

### 2. Настройка Keycloak
При первом запуске необходимо настроить Realm (если он не импортировался автоматически):
1.  Зайти в админку: `http://localhost:8180` (admin / admin).
2.  Создать Realm `courier-realm`.
3.  Создать Client `courier-app`.
4.  Включить `Direct Access Grants`.
5.  Настроить Web Origins (CORS) на `*`.

## Сценарий использования (Demo Flow)

Весь интерфейс доступен по адресу: **http://localhost:8089**

### Шаг 1: Подготовка Курьера
1.  Откройте страницу регистрации (`/register.html`).
2.  Выберите вкладку **"Я Курьер"**, заполните данные.
3.  После входа вы попадете в кабинет курьера.
4.  Нажмите переключатель **"На линию"** (статус станет `FREE`).

### Шаг 2: Создание Заказа
1.  Откройте новое окно (инкогнито) или другой браузер.
2.  Зарегистрируйтесь как **Клиент**.
3.  Введите адрес и нажмите **"Найти курьера"**.

### Шаг 3: Магия (Dispatching)
1.  У Курьера всплывет окно **"Новый заказ"** с таймером 30 секунд.
2.  Нажмите **"Принять"**.
3.  У Клиента обновится статус: *"Курьер найден"*.
4.  Курьер нажимает **"Забрал товар"** -> **"Вручил"**.
5.  Клиент получает уведомления на каждом этапе.
